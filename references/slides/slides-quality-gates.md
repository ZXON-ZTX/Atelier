# 幻灯片质量底线与反模板味清单(Slides Quality Gates)

来源:academic-pptx 学术军规、guizang 自检清单、CyberPPT 质量门、
frontend-slides 预览真实性规则、dashi 验收原则。
分 **C 组(构建时参考)**与 **S 组(交付前按任务检查)**。检查状态与证据对应，
未运行的检查标为未验证；已有品牌、模板和用户指定的视觉要求优先。

## C 组:构建时底线

- [ ] 内容页有中心意思，标题优先论点句；封面、目录、章节和练习页标题按角色安排。
- [ ] 大纲主线连贯，仅读标题也能理解主要内容。
- [ ] 正文按场景控制密度；普通口头演示少文字，教学推导与证据表可适度增加。
- [ ] 全 deck 使用一致的网格和字体，内容页按信息类型选择同一家族的不同版式。
- [ ] 主强调色明确；辅助色与图表色按需使用，不抢夺层级，学术稿优先少量协调颜色。
- [ ] 数据真实:每个数字有来源,每个图表有单位与脚注。
- [ ] 页数与内容、时长匹配；用户给定的页数与范围优先。
- [ ] 图片有出处/授权(免版权图库或自有素材),无 AI 假人像充数。
- [ ] 按任务提供演讲备注，通常每页 2–4 句提示；需要全文讲稿时遵守用户要求。

## S 组:反模板味(slop)清单 —— 交付前逐项勾掉

**结构**
- [ ] S1 无 Office 默认模板脸(蓝白 SmartArt、默认渐变底、模板占位图)。
- [ ] S2 无"标题 + 一堆 bullet"全 deck 单一版式;内容页型按信息类型混用。
- [ ] S3 无 3 张等宽"三卡片"万能页(有真实三点时才许用,且三点须真实不同)。
- [ ] S4 尾页能收束内容，如结论、行动号召或带联系信息的致谢；用户模板优先。

**文字**
- [ ] S5 内容页标题尽量传递具体结论，其他页面使用适合其角色的标题。
- [ ] S6 正文无空话("赋能""闭环""抓手"式腔调);每句有信息量。
- [ ] S7 常规正文建议 18–20pt、标题 24–32pt，图注与脚注采用版式规范的层级，实际渲染后检查可读性。
- [ ] S8 无错别字，中英文术语一致，无截断与溢出。

**视觉**
- [ ] S9 无默认紫蓝渐变、无 3D 小人、无图库握手图/白板图。
- [ ] S10 无 emoji 当图标;图标体系统一且与风格方向一致。
- [ ] S11 阴影、圆角和动效服务内容；整页过渡克制，元素入场可按风格使用，不干扰阅读。
- [ ] S12 对比度达标:正文与底色 ≥ 4.5:1;深色页同样检查。
- [ ] S13 图文对齐协调，无明显错位、叠字或图片遮挡文字。

**图表**
- [ ] S14 每个图表有 so-what 注释;关键数据就地高亮。
- [ ] S15 无"假数据点名"图(没数据就不画图,改文字表达)。
- [ ] S16 图表风格与所选风格方向一致(瑞士风不画 3D 饼图)。

**工程**
- [ ] S17 HTML deck:翻页可用、内容可读；离线、PDF 导出和演讲者模式按要求实现并验证。
- [ ] S18 PPTX:主要文字与形状可编辑；有渲染工具时逐页检查溢出、遮挡与母版残留，未渲染则标记未验证。
- [ ] S19 较长 deck 根据演示用途提供页码或章节导航。
- [ ] S20 素材出处页/致谢(引用了外部素材时)。

## 自查流程(有界)

1. 先检查大纲、内容与版式，按任务选择相关清单项；其他格式的项标为不适用。
2. 有渲染能力时逐页看成品，批量修复缺页、溢出、遮挡等影响使用的问题，
   再检查受影响页面和共用布局。审美微调通常一轮即可。
3. 还有阻断问题时继续修复，确实无法完成则明确说明；缺少渲染工具时可
   交付已生成的文件与结构检查结果，注明视觉验收未完成。
4. 交付时简短列出已检查、未验证与不适用项，不固定宣称“20 项全部通过”。
