# 幻灯片风格方向分类法(12 个方向)

融合自 guizang-ppt 双风格、frontend-slides 预设、CyberPPT 8 风格、
dashi 主题、academic-pptx 学术规范。每个方向 = 配色 + 字体 + 版式 + 图表 +
动效的完整签名。需要探索时从表中选合适方向，已有模板与用户参考优先。

---

### 1. 电子杂志风 Editorial Magazine
来源:guizang-ppt 风格 A(默认);Monocle 杂志美学。
- 签名:大衬线主标题、等宽元数据、大幅留白网格、hero 页与普通页交替;
  **克制优于炫技**——不用阴影/浮动卡片/圆角盒,层级全靠字号与字体对比。
- 配色:纸色底 + 墨黑 + 单一强调色;5 套主题可选。
- 字体:衬线展示(如 Noto Serif SC)+ 无衬线正文 + 等宽元数据。
- 图表:手绘感线条图/极简条形,数据点即装饰。
- 动效:几乎无;WebGL 只允许 hero 页透出。
- 适用:行业观察、人文故事、文化品牌、内容型汇报。

### 2. 瑞士国际主义 Swiss Grid
来源:guizang-ppt 风格 B;Müller-Brockmann 网格系统。
- 签名:12 列网格、左对齐 + 大幅留白、1px hairline 分割线、
  **单一锚点色**(一份 deck 以一个 accent 为主)、标题与副标题层级清楚；
  巨型字号仅用于封面和 Data Hero，普通内容页遵循统一字号标尺，
  KPI 做成 "Data Hero"，数字尺寸围绕结论与留白调整。
- 配色:纯白/近白底 + 黑 + 一个锚点色(红/蓝/绿择一)。
- 字体:只允许无衬线(Inter/Helvetica/Noto Sans SC),出现衬线即错。
- 图表:扁平、直角、无渐变无阴影;信息图式表达。
- 动效:硬切或极简位移。
- 适用:数据汇报、产品发布、工程/技术、信息图式内容。

### 3. 现代极简 Modern Minimal
来源:frontend-slides 安全预设;Linear/Stripe 审美。
- 签名:冷色中性底、细边框卡片、克制动效、留白呼吸感。
- 配色:近白底 + 黑字 + 单一冷强调(蓝/靛)。
- 字体:现代无衬线(避免默认 Inter 模板感,可用 Space Grotesk/Geist)。
- 图表:细线图、无框表格、数据轻量。
- 动效:淡入 + 交错揭示(staggered reveal),CSS only。
- 适用:SaaS、创业公司路演、产品介绍。

### 4. 咨询风 Consulting(MBB 式)
来源:CrazyPPT/CyberPPT、Mck-ppt-design-skill(70 版式)、academic-pptx 结构。
- 签名:**SCR 叙事**(Situation-Complication-Resolution)、论点式标题
  (action title)、高信息密度、证据表、页面结构骨:标题条 + 内容区 + 来源
  脚注 + 页码。
- 配色:白底 + 深藏青标题条 + 单一强调色(机构蓝/深绿)。
- 字体:无衬线(Arial/Calibri/微软雅黑级),标题加粗。
- 图表:数据驱动——瀑布图、树状图、矩阵;每个图表配 "so-what" 注释。
- 动效:无或极简。
- 适用:商业汇报、战略、咨询交付、融资 BP。

### 5. 学术严谨 Academic
来源:academic-pptx-skill(communication-first 设计)。
- 签名:白底内容页、最多三色(深藏青主色 1F4E79 + 中蓝强调 2E75B6)、
  左对齐、图左文右、引用脚注、参考文献尾页。
- 字体:单一无衬线(Arial/Calibri/Helvetica),用字号与字重分级。
- 图表:学术图表,关键发现直接高亮标注,每图注明出处。
- 动效:无。
- 适用:论文答辩、学术会议、组会、基金申请。

### 6. 发布会大气 Keynote
来源:frontend-slides 大胆预设;苹果发布会/大厂 keynote 美学。
- 签名:深色舞台感、超大字号(单页甚至只放一个词/一个数字)、
  全屏图 + 巨型标题、节拍感强烈。
- 配色:深黑/深灰底 + 白 + 一个高饱和强调。
- 字体:加粗展示无衬线,字重对比极端。
- 图表:Data Hero 一个数字撑满整页,图表极简。
- 动效:一页一个高冲击入场(缩放/遮罩揭示),不撒胡椒面。
- 适用:新品发布、融资路演、大型活动开场。

### 7. 科技深色 Tech Dark
来源:guizang 瑞士风的深色变体;AI 产品审美;frontend-slides Neon 系。
- 签名:深色底 + 发光强调、代码块点缀、终端/玻璃质感(克制使用)。
- 配色:深底(L<30%)+ 磷光绿/青/紫单强调,禁止紫蓝双渐变堆砌。
- 字体:无衬线 + 等宽混排。
- 图表:暗色图表、高亮关键序列。
- 动效:光晕呼吸、逐行揭示(有度)。
- 适用:AI/开发者产品发布、技术分享、黑客松。

### 8. 活力渐变 Playful/Vibrant
来源:dashi 主题、frontend-slides 活泼预设。
- 签名:亮色底、渐变(有意识地用,不撞紫蓝默认)、圆角、插画与统一图标、
  活泼文案。
- 配色:奶油/浅底 + 珊瑚/黄/薄荷撞色。
- 字体:圆体无衬线。
- 图表:拟物/手绘感图表。
- 动效:弹性入场、翻页小彩蛋。
- 适用:消费品牌、教育课件、团队内部分享、社群活动。

### 9. 复古印刷 Retro Print
来源:risograph 美学;guizang 杂志风的印刷变体。
- 签名:riso 错版、网点纹理、复古窄体字、报纸式多栏。
- 配色:高饱和红蓝黄 + 米纸底,故意叠色错位。
- 字体:窄体展示 + 衬线正文。
- 图表:印刷风统计图、手写标注。
- 动效:印刷机式逐条揭示。
- 适用:文创、音乐、独立品牌、年度回顾。

### 10. 自然有机 Natural
- 签名:大地色、有机曲线、植物/手工质感,暖光感。
- 配色:叶绿/土棕/米白。
- 字体:人文衬线或圆体。
- 图表:手绘线图、环形占比。
- 动效:轻微视差、生长动画。
- 适用:农业、食品、环保、健康、教育低龄向。

### 11. 奢华高端 Luxury
- 签名:低对比、细字重、超大留白、真材质感图片,贵在细节。
- 配色:米白/香槟/炭黑 + 金/铜点缀。
- 字体:优雅衬线(Didot/Cormorant)+ 细无衬线。
- 图表:极简,数字本身即展示。
- 动效:极慢渐显。
- 适用:高端品牌、珠宝、酒店、私人服务、闭门分享。

### 12. 极简黑白 Mono Minimal
- 签名:纯黑白、字重与留白构成全部视觉,网格极简。
- 配色:纯白 + 纯黑,无彩色。
- 字体:单一无衬线,字重分级。
- 图表:黑白线图。
- 动效:硬切。
- 适用:设计师个人分享、概念型发布、预算极简场景。

## 选择与组合规则

- **一个 deck 一个主方向**;可从相邻方向借 1 个元素(如瑞士风 + 一个杂志
  风章节页),但不得混成"四不像"。
- 通过 90% 意图门或明确委托后，简短说明主方向再执行。
- 同品牌、同系列和修改稿沿用已确认的风格与版式；用户请求探索方案时才主动拉开差异。
- 用户给了参考 deck/截图 → 用参考的 DNA 覆盖本表对应签名(参考优先)。
- 用户自定义品牌色 → 锚点优先,调色板围绕锚点重配,方向其他签名不变。
- 有机构模板(校徽/官方 VI)→ 模板锁定,只在本表内选与之兼容的版式语言。
