# 幻灯片意图确认门 · 90% 置信度

与网页共用 Atelier 的六轴加权门，先确认演示设计意图，再制作完整稿件。
评分表示确认程度，不是统计正确率。通用规则见[网页意图门](../intent-gate.md)。

## 幻灯片的六轴

| 轴 | 信号 | 权重 | 确认依据 |
|---|---|---|---|
| A | 演示场景/类型 | 15% | 路演、汇报、教学、学术或发布 |
| B | 受众与场合 | 10% | 投资人、领导、学生、会议听众等 |
| C | 风格方向 | 30% | 用户指定、参考稿或选中的风格预览 |
| D | 品牌/机构锚点 | 25% | 品牌色、字体、机构模板或明确无品牌约束 |
| E | 内容结构与页数 | 10% | 大纲、页数、时长或已确认的页型 |
| F | 参考与灵感 | 10% | 参考 deck、截图、旧 PPT 或明确不需要参考 |

每轴明确确认 1.0、有依据的强推断 0.7、弱线索 0.4、未知 0。
总置信度 = Σ(权重 × 轴值)，达到 **90%** 才开始最终设计；
不足时每轮补一个最大缺口，最多三轮。之后给具体方案供确认，不能自动补满分。
每轴保留依据。沿用旧 PPT 时已有字体、配色和页型可直接计入，不重问。

“直接做 / 你定 / 不用问”沿用明确委托路径：写“按用户委托通过”，
说明重要假设后执行，不虚构百分数。缺失必需的原始资料仍需补齐。
确认单用两三行说明实际分数或委托状态、页数/格式、风格与内容依据。

## 制作前确定执行信息

- 明确要求 PPT / PowerPoint / PPTX 时默认可编辑 PPTX；要求 HTML 或浏览器
  演示时采用 HTML。提前选择制作路线，不重复问已指定的格式。
- 原始素材、事实数据与工具能力另行确认；风格通过门不能替代事实材料。
- 页数已指定就遵守。用户委托时按内容给合理结构；必要时讨论大纲，已有
  大纲或已委托时不另外等待一次形式批准。

## 风格确认与预览

选择代价最低的方式：

1. 已有明确方向或参考：提取字体、配色和版式，更新相关轴。
2. 用户想探索但不需要图：从[风格库](slides-style-taxonomy.md)给两三个合适选项。
3. 用户说不清风格或想看图：先做两三张字体、配色、布局可辨的单页风格预览。
   预览可以在门未通过时制作，使用真实主题与可用素材；缺少作者等信息先省略。
   无法输出图片时可制作可打开的 HTML 或 PPTX 预览，并说明展示方式。

**选中预览先更新 C，再按确认内容更新 D/E/F 并重新计算。**
只有同时确认了配色、布局等内容才能更新对应轴；不把选图自动等同于通过 90%。
预览元素应能迁移到目标交付格式，避免选中的效果无法做成 PPTX。

## 大纲与执行

- 先安排主线，再设计页面；内容页优先论点式标题，封面、目录、章节和练习页
  使用适合其角色的标题。风格探索预览可以提前制作。
- 内容页按图表、流程、对比与要点选同一页面家族的不同版式。
- 用户已指定的品牌、模板和同系列设计优先；通过门后保持一致。
- 通过意图门或明确委托后制作；已有大纲不重复要求批准，缺少关键内容且
  未获委托时才补问。
- 数字、研究结果与引用有来源；没有材料不编造结果。
