# 幻灯片版式系统(Slide Layouts)

来源:academic-pptx 的每页规则、guizang 的网格哲学、Mck 的 70 版式精华、
dashi 的页面角色。一个 deck 的版式系统 = 封面型 + 章节型 + 内容型 + 尾页型,
封面、章节和尾页保持各自稳定的样式；内容页按信息类型选择同一家族中的版式。

## 1. 页面角色与选型

### 封面(1 页,定全场基调)
| 型 | 描述 | 适合 |
|---|---|---|
| C1 大字宣言 | 整页一个巨型标题 + 小号副标/日期 | 发布会、路演、杂志风 |
| C2 居中标题 + 全屏图 | 图上压标题,氛围优先 | 大气、人文、品牌 |
| C3 左文右图 | 文字区 + 关键视觉分栏 | 商务、产品、学术 |
| C4 网格信息封面 | 标题 + 元数据(作者/日期/机构)严格对齐网格 | 瑞士风、咨询、学术 |

### 章节页(Divider,有多个主题章节的长 deck 可用)
- 型:D1 大数字章节号 + 章节名;D2 全屏色块 + 章节名;D3 面包屑式(当前
  章节高亮)。**章节页让长 deck 不迷路**,也是节奏呼吸点。

### 内容页(核心,按信息类型选)
| 型 | 描述 | 铁律 |
|---|---|---|
| T1 论点标题 + 要点 | 标题优先论点句,3–5 个支撑点 | 每点尽量两行以内，按场景控制信息密度 |
| T2 三栏卡片 | 三个并列模块 | 卡片之间必须真实不同,禁止模板脸 |
| T3 Data Hero | 一个突出的大数字或图表 + 一句解读，尺寸按风格与内容调整 | 数字有依据，结论清楚 |
| T4 大图 + so-what | 图/截图占 60%+,右侧一行结论 | 图必须是证据不是装饰 |
| T5 双栏对比 | 左 vs 右(现状 vs 方案 / 竞品 vs 我们) | 对比轴明确,结论显式 |
| T6 时间轴/流程 | 横向或纵向节点 | 节点 ≤ 7 个,每节点一句话 |
| T7 全屏引用 | 整页一句引言 | 必须真引用,署名+出处 |
| T8 证据表 | 表格呈现数据/清单 | 关键行高亮 + 来源脚注 |

### 尾页(最后一页 = 观众合影页,不是句号)
- 型:E1 结论回顾(3 条 takeaway,常驻 Q&A);E2 行动号召(CTA + 联系方式/
  QR);E3 致谢 + 联系。学术 deck 优先用结论回顾收束；用户模板要求致谢时保留。

## 2. 网格与排版规范(所有页面)

- 16:9 为默认；已有文件、模板或用户指定的比例优先，无需每次重问。
- 统一边距(≥ 屏宽 4%);所有元素吸附同一网格(推荐 12 列)。
- 字号标尺作为建议(投影场景，需结合实际渲染调整):
  - 论点标题 24–32pt 加粗;节标题 20–22pt;正文 18–20pt;
  - 图表标注 14–16pt;来源脚注 10–12pt 灰。
- 展示与正文通常使用两种以内的字体；确需代码或数据标签时可加等宽字体。
  中文字体需支持实际文字，层级靠字号/字重，不靠增加字体种类。
- 左对齐为主,标题可居中;对比度 ≥ WCAG AA。

## 3. 图表语言(每类风格都有自己的图表语言)

- 每个图表配一个 **so-what 注释**(一句话说出读者该带走什么)。
- 关键数据点**就地高亮**(锚点色/加粗),不让观众自己找。
- 图表必带:标题或图例、单位、来源;数字不造假、不画没数据的图。
- 风格对应:杂志风→手绘线图;瑞士风→扁平信息图;咨询风→瀑布/矩阵;
  学术→期刊级图表;发布会→Data Hero。

## 4. 输出格式选择(制作前确定，已指定则不重复问)

| 格式 | 优点 | 何时选 |
|---|---|---|
| **HTML 幻灯片** | 浏览器演示，按需实现动效、打印 PDF 与演讲者模式 | 明确要求 HTML 或浏览器演示 |
| **可编辑 PPTX** | 对方要用 Office/WPS 继续改，主要文字和形状保持可编辑 | 用户说做 PPT / PowerPoint / PPTX 时默认采用 |
| 两者都要 | 演示 + 留底 | 明确要求时 |

PPTX 生成路线(在宿主里执行):
- python-pptx(精确控制,适合咨询/学术风);
- pptxgenjs(Node,布局快);
- OfficeCLI 或其他原生工具(仅在环境实际可用时使用)。
有渲染能力时逐页看成品并修复；没有时检查文件可打开与内容结构，交付时
标记视觉验收未完成。不要把无法运行的检查勾选为通过。

## 5. 常见崩坏模式(源自 Mck 教训,每次动工前读)

1. 无证据宣布验收成功——说明实际检查范围与未验证项。
2. 先做封面后想结构——先安排大纲，再做页面；风格探索预览可以提前制作。
3. 风格漂移——沿用确认过的字体、配色、网格与页面家族，不逐页重复声明。
4. 信息过载——优先拆分信息或用备注承接；保留用户必需内容与页数约束。
5. 模板味——按信息类型选版式；用户提供的机构模板仍需遵守。
