# 质量底线与反 AI 味清单(Quality Gates)

设计执行与自查的参考。用户已确认的品牌与视觉要求优先；可读性和主要操作仍需检查。分两组:
**C 组(构建时遵守)**与 **S 组(交付前逐项勾掉的反 slop 检查)**。

## C 组:构建时底线

- [ ] 语义化 HTML;标题层级唯一且连续;按钮是真按钮。
- [ ] 对比度 ≥ WCAG AA(正文 4.5:1,大字 3:1);focus-visible 可见。
- [ ] 4/8pt 间距节奏;同元素同类间距一致。
- [ ] 三档响应:手机 / 平板 / 桌面,关键操作不折叠消失。
- [ ] 动效有目的:解释状态变化、引导注意、奖励完成;默认减量,
      尊重 prefers-reduced-motion。
- [ ] 真实内容:无 lorem ipsum;图片有 alt;文案具体不空洞。
- [ ] 设计 token(CSS 变量)先行;颜色、字号、间距不散落硬编码。
- [ ] 主要内容和交互完整；演示数据已标注，缺少必需材料时明确说明。

## S 组:反 AI 味(slop)清单 —— 交付前逐项勾掉

来源:Hallmark 57 门反模式、taste-skill 自检、UI UX Pro Max 推理规则之精炼。

**视觉**
- [ ] S1 无默认紫→蓝渐变 hero(紫渐变本身不是原罪,裸用才是)。
- [ ] S2 无 emoji 当图标;图标体系统一(线条或实心,不混用)。
- [ ] S3 无"居中三段式 + 圆角卡片"模板脸;页面有自己的结构指纹。
- [ ] S4 无默认 Inter 配默认蓝的"模板感";字体选择与风格方向一致。
- [ ] S5 无 3px 阴影大圆角的"AI 卡片"堆砌;层级靠排版与留白,不靠阴影堆。

**文案**
- [ ] S6 无 "unlock / elevate / seamless / revolutionize / supercharge"
      及其直译("解锁/赋能/无缝/颠覆")式空洞营销腔。
- [ ] S7 无 "Discover the power of..." 式万能副标题。
- [ ] S8 CTA 具体("Start free 14-day trial"),不空洞("Get Started")。
- [ ] S9 无多余的感叹号与火箭/✨ emoji 堆砌。

**结构**
- [ ] S10 无 3 张等宽"三卡片"万能 section(有真实三卖点时才许用)。
- [ ] S11 无 "假数据点名"图表(没有数据就别画图)。
- [ ] S12 无 5 个圆点滑块 testimonials 模板;
       有真实评价则用真实评价并以不同形态呈现。
- [ ] S13 页脚不是 4 列链接矩阵 + 版权行的 AI 指纹;按页面真实信息设计。

**内容**
- [ ] S14 无 AI 生成的假人脸/假 logo;用真实人像(可用免版权图库)或不做。
- [ ] S15 配图与页面情绪一致,不是图库第一页的握手/白板照。
- [ ] S16 无 lorem ipsum / "placeholder" 注释 / 空 href。

**工程**
- [ ] S17 无内联样式堆砌;无未使用的 CSS 块。
- [ ] S18 移动端首屏不挤、无横向滚动、点击目标 ≥ 44px。
- [ ] S19 性能:首屏关键图片及时加载，LCP 图片不懒加载；非首屏图片按需懒加载，大图声明尺寸避免布局抖动。
- [ ] S20 无障碍:键盘可达、表单有 label、图片有 alt、语义正确。

## 自查流程(有界)

1. 先检查内容层级、布局、主要操作和图片；根据任务选择相关清单项。
2. 有浏览器时检查桌面、平板和手机代表尺寸，截图并查看实际成品；
   批量修复遮挡、溢出、不可操作等问题，再复查受影响页面与共用样式。
3. 配色、留白等审美微调通常做一轮；关键操作或内容仍有问题时继续修复，
   无法修复则交付时明确说明，不把修复轮数当作通过依据。
4. 简短记录已检查、未验证和不适用项。没有浏览器或只检查了部分尺寸时
   如实说明，不固定宣称“20 项全部通过”。
