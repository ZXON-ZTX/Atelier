# 风格方向分类法(12 个方向)

融合自 Hallmark 的 21 主题、taste-skill 的 20 个研究方向、UI UX Pro Max 的
79 种风格。每个方向 = 调色板 + 字体 + 布局 + 动效的完整签名。
需要探索选项时,从表里挑两三个合适的方向；用户已有方向或品牌系统时直接沿用。

---

### 1. Editorial 编辑杂志风
来源:Hallmark Specimen/Newsprint/Atelier + taste editorial。
- 签名:大号衬线标题、编号栏标签、不对称留白、纸感底色、文字即装饰。
- 配色:纸色(近白米黄)+ 墨黑 + 单一暖强调(深红/焦橙)。
- 字体:高对比衬线(如 Playfair/Newsreader)+ 等宽标注。
- 动效:几乎无;最多淡入与锚点滚动。
- 适用:内容品牌、媒体、文化机构、个人专栏。

### 2. Modern-Minimal 现代极简
来源:Hallmark Coral/Cobalt;Stripe/Linear/ElevenLabs 流派。
- 签名:冷色中性底、细边框分割、小而精的动效、大量留白。
- 配色:近白/浅灰底 + 单一冷强调(蓝/靛)+ 黑字。
- 字体:几何/怪诞无衬线(Inter/Space Grotesk)+ 单色点缀。
- 动效:subtle hover、滚动渐显,克制。
- 适用:SaaS、开发者工具、B2B、企业官网。

### 3. Atmospheric 氛围暗色
来源:Hallmark Bloom/Midnight/Aurora/Lumen;Suno/Runway 流派。
- 签名:深夜底、发光渐变、深色玻璃、大氛围图首屏。
- 配色:深底(L<30%)+ 双发光强调(紫/青或粉/橙),谨慎使用紫渐变。
- 字体:无衬线展示 + 等宽细节。
- 动效:光晕呼吸、粒子、缓动镜头感,适可而止。
- 适用:AI/音乐/视频/游戏/夜间感产品。

### 4. Playful 活泼软萌
来源:Hallmark Hum;post-Linear 柔和派。
- 签名:圆角、暖色、手绘感插画/SVG、友好的微文案。
- 配色:奶油底 + 珊瑚/黄/薄荷。
- 字体:圆体无衬线(Plus Jakarta/Quicksand)。
- 动效:弹性弹簧、笑脸级细节动效。
- 适用:消费、社区、教育、家庭、onboarding。

### 5. Brutalist 粗野工业
来源:Hallmark Brutal;taste industrial-brutalist。
- 签名:硬边框、瑞士式大字、强对比、实验性布局、故意"生硬"。
- 配色:纯黑白 + 一个刺眼强调(荧光黄/正红)。
- 字体:Neue Haas/Grotesk 级 + 等宽。
- 动效:瞬时切换、无缓动或极硬缓动。
- 适用:设计工作室、独立厂牌、艺术展览、想显得不羁的品牌。

### 6. Luxury 奢华克制
来源:taste high-end-visual-design;Hallmark 定制线。
- 签名:低对比、细字重、大留白、真材实料感图片、贵在细节。
- 配色:米白/香槟/炭黑 + 金或铜点缀。
- 字体:优雅衬线(Didot/Cormorant)+ 细无衬线。
- 动效:极慢渐显、spring 轻弹。
- 适用:高端品牌、珠宝、酒店、私人服务。

### 7. Swiss/Studio 瑞士平面
来源:Hallmark Studio/Manifesto。
- 签名:网格统治、海报式大标题、锐利裁剪、几何色块。
- 配色:红/黑/白经典三色,或双色撞色。
- 字体:Helvetica 系/加粗 grotesk,全大写展示。
- 动效:切页式滚动、位移动画。
- 适用:设计公司、活动页、宣言式品牌。

### 8. Terminal/Tech 终端技术风
来源:Hallmark Terminal;开发者工具流派。
- 签名:等宽字体、命令行界面隐喻、绿色/琥珀磷光、ASCII 装饰。
- 配色:近黑底 + 磷光绿/琥珀 + 灰阶。
- 字体:JetBrains Mono/Space Mono。
- 动效:打字机、光标闪烁、逐行揭示。
- 适用:开发者工具、CLI 产品、黑客松、技术博客。

### 9. Natural/Organic 自然有机
来源:Hallmark Garden;taste 有机方向。
- 签名:大地色、有机曲线、植物元素、手工质感。
- 配色:叶绿/土棕/米白 + 暖光。
- 字体:人文衬线或圆体。
- 动效:叶子摆动级微动效、视差。
- 适用:农业、食品、环保、健康品牌。

### 10. Retro/Print 复古印刷
来源:Hallmark Riso/Almanac/Sport;risograph 风。
- 签名:riso 印刷错位、网点纹理、复古字体、报纸排版。
- 配色:高饱和红蓝黄 + 米纸底,故意错版叠色。
- 字体:窄体/展示体(Condensed)+ 衬线正文。
- 动效:印刷机式揭示。
- 适用:文创、独立出版、音乐节、市集。

### 11. Glass/Gradient 玻璃拟态渐变
来源:UI UX Pro Max 玻璃/渐变系;Hallmark Aurora。
- 签名:磨砂玻璃卡片、柔和弥散渐变、圆角胶囊、深色或浅色底。
- 配色:底 + 半透明白/黑层,弥散双色渐变(避免默认紫)。
- 字体:现代无衬线。
- 动效:悬浮、视差层。
- 适用:App 落地页、AI 产品、金融科技(注意别掉进 slop)。

### 12. Data/Dev 极客数据风
来源:Hallmark Grid/Bento;开发者向。
- 签名:Bento 网格、图表感模块、等宽数据标签、深色代码块点缀。
- 配色:深底或白底 + 蓝/绿数据色 + 等宽灰。
- 字体:无衬线 + 等宽混排。
- 动效:计数器、图表绘制动画。
- 适用:分析工具、API、开发平台、技术报告。

---

## 选择与组合规则

- **一个页面一个主方向**;可从相邻方向借 1 个元素(如极简 + 一个粗野按钮)。
- 通过 90% 意图门或明确委托后，用简短确认单写清主方向。
- 同品牌、同系列和修改稿保持风格与布局的一致性；用户请求探索方案时才主动拉开差异。
- 客户给了参考图/链接 → 用参考的 DNA 覆盖本表对应签名(参考优先)。
- 客户自定义品牌色 → 锚点优先,调色板围绕锚点重配,方向其他签名不变。
