# 布局原型(10 个)

来源:融合 Hallmark 的 21 种 macrostructure 与常见页面形态。
选一个原型,页面骨架即定;细节由风格方向签名填充。

| # | 原型 | 一句话描述 | 适合 |
|---|---|---|---|
| L1 | Hero Marquee 大字首屏 | 首屏整版大标题 + 一个 CTA,内容在其下展开 | 大多数落地页 |
| L2 | Split Hero 左右分栏 | 左文右图(或反之),首屏即说明产品 | SaaS、App 推广 |
| L3 | Bento Grid 便当网格 | 3–12 块不同尺寸模块拼成网格 | 功能多、开发者产品 |
| L4 | Long-Form Editorial 长文叙事 | 长篇滚动,章节化,图文穿插 | 品牌故事、案例、媒体 |
| L5 | Manifesto Poster 海报宣言 | 首屏即海报,大字宣言+超大图形 | 活动、工作室、宣言页 |
| L6 | Terminal Window 终端窗口 | 页面像终端/编辑器界面 | 开发者工具、CLI |
| L7 | Gallery Showcase 作品画廊 | 作品主导,网格/瀑布流,悬停预览 | 作品集、画廊、摄影 |
| L8 | Product Config 产品展示 | 中央产品大图,四周参数/说明 | 硬件、SaaS 功能页 |
| L9 | Dashboard Shell 仪表盘壳 | 侧栏 + 顶栏 + 内容区骨架 | 后台、App UI、数据产品 |
| L10 | Story Scroll 故事滚动 | 逐屏故事,滚动驱动章节推进 | 品牌故事、众筹、年度报告 |

## 使用规则

- 原型 = 骨架,不是模板:标题位置、图文比例、模块数按内容调整,
  独立项目按内容形成自己的结构，同品牌页面可以沿用已确认的骨架。
- 导航与页脚是"结构指纹"的一部分,同样要选择:
  导航(最小两链接 / 经典三区 / 悬浮胶囊 / 侧栏 / ⌘K / 报头式…),
  页脚(声明式 / 链接矩阵 / 极简单行…);同产品与同品牌默认沿用已确认的组合。
- 与风格方向交叉:如 Editorial × L4(长文)是经典对;Glass × L3(Bento)
  是流行对;故意错配(如 Brutalist × L2)可产生辨识度,但需 brief 支持。
